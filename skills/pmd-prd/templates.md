# 双文档模板入口（仅导航）

需要生成、冻结或校验两份正式正文时，先完整读取同目录 [`references/templates.md`](references/templates.md) 的全部内容。该文件包含固定六部分研发交接包、公司 PRD 模板和填写规则，是两份最终产物的唯一权威正文结构；本文件不提供可替代的摘要模板。

阶段 5 将完整正文原样落到同一过程目录，规范文件名为 `{需求标识}_{主题}_01_需求分析与研发交付.md` 与 `{需求标识}_{主题}_02_PRD.md`，再运行 `scripts/validate-deliverables.mjs`。只有校验通过，才允许以“需求分析、PRD”的固定顺序进入 batch preview。

缺失必填信息使用 `[待确认]` 并说明影响；选填项不适用使用“不适用（原因）”。生成正文必须保留权威模板的全部章节、顺序、关键表头和必填/选填标记；公司 PRD 正文不得追加附录或改写。
