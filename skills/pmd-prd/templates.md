# 单 PRD 模板入口（仅导航）

需要生成、冻结或校验正式正文时，先完整读取同目录 [`references/templates.md`](references/templates.md) 的全部内容。该文件包含唯一 PRD 的完整模板和填写规则；本文件不提供可替代的摘要模板。

阶段 5 将完整 PRD 正文原样落到同一过程目录，规范文件名为 `{需求标识}_{主题}_PRD.md`，再运行 `scripts/validate-deliverables.mjs --prd <prd-frozen-path>`。只有校验通过，才允许以一项 PRD 进入 batch preview。

缺失事实使用 `[待确认]` 并说明影响；不适用使用“不适用（原因）”。生成正文必须保留权威模板的全部章节、顺序和关键表头。第四章每个功能必须包含“现状、调整方式、输入/输出规则、调整后效果”；第八章必须同时保留“异常场景关注点”和新增的五类“验收清单”。最终标题和正文不得出现 `[必填]`、`[选填]` 或 `[建议填写]` 字段标签。
