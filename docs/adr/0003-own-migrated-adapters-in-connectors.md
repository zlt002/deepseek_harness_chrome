# Own migrated adapters in independent connectors

Office and knowledge adapters will move into Connector-owned modules instead of making the Harness product depend on the AccrUI repository or its full Agent Backend. The first milestone consists of three independently accepted Migration Slices—spreadsheet read/write/read-back, knowledge and code query with sources, and single online-document creation with body read-back—using generic Harness tool cards on macOS Chrome. AccrUI remains the comparison and fallback until every slice crosses its Parity Gate.
