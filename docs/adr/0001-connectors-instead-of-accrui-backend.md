# Integrate AccrUI capabilities as Harness connectors

DeepSeek Harness remains the single agent workspace. Office and knowledge capabilities will be exposed through independent connectors and Harness tools rather than by embedding AccrUI's sidepanel or carrying its complete Agent Backend into the new product. This preserves Harness sessions, models, plugins, and permissions while allowing the browser-specific adapters to migrate independently; reads may run automatically, while mutations require approval and only succeed after target read-back.
