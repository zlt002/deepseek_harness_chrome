## 3. 现状证据摘要（H5_前端，Evidence ID 见 knowledge-sources.md）

- 存在两条接单链路：
  - 链路 A（货源大厅主动接单）：列表卡片 → 详情页 → 接单/报价确认页，按 `freightType` 0抢单/1报价/2认领/3一口价 分派（EV-01/02/03/04/05）。
  - 链路 B（任务详情派单接单）：`confirmReceivingOrders` 手动接单 + `orderAutoAcceptFlag` 服务端自动接单倒计时，前端只做倒计时展示与刷新（EV-06/07）。
- 状态字段：`driverConfirmStatus`('20'已接/'30'拒绝)、`driverTaskStatus`(60/70/50)、`driverOrderStatus`(0/1)；`supplyHallDetail.ts:167` 注释与运行值不一致（EV-08）。
- 交互与防护：`showZtbDialog` 命令式弹窗体系；详情页 4 个倒计时定时器；防重仅 `isLoading`/`isLock` 状态锁，无统一防抖（EV-03/09/10）。
- 成功流转：接单成功 → 押金判断 → 支付弹窗/跳找货记录页（EV-13）。
- 实时性短板：全仓库无 WebSocket/SSE，实时能力依赖原生 dsBridge；超时下架靠重新拉详情驱动；请求封装 60s 超时、无自动重试（EV-11/12）。
- 无接单专用 store；相关 store 为 user/task/queryParams（EV-14）。
